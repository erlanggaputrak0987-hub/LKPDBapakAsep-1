Apa yang kamu temukan tentang operator %?

Yang saya dapat dari operator % adalah operator untuk melihat sisa bagi. Dimana, akan menghasilkan sisa bagi dari suatu bilangan dibagi bilangan lainnya. Contoh, 20 : 4 = 5, hasilnya bulat sudah tidak ada sisa lagi maka 20 % 4 = 0

3. Perintah Input prompt()

let nama = prompt("Masukkan Nama:");

4. Konversi Data Number()

Secara bawaan prompt() mengembalikan data berjenis Teks (String). Gunakan Number() agar bisa dihitung secara aritmatika.

let angka = Number(prompt("Isi Angka:"));
