Apersepsi

Apersepsi

Bayangkan kamu sedang membuat aplikasi data siswa. Program perlu mengetahui:

  • Nama siswa
  • Kelas
  • Umur
  • Nilai
  • Jurusan

Contohnya:

  • Nama siswa = "Budi"
  • Kelas = "XI RPL 1"
  • Umur = 16
  • Nilai = 85

Menurutmu, bagaimana cara menyimpan informasi tersebut di dalam program? Tuliskan dugaanmu:

Informasi tersebut disimpan di dalam sebuah "wadah" atau tempat penyimpanan data yang diberi nama, sehingga program bisa memanggil dan memakainya kembali kapan saja. Wadah ini disebut variable, misalnya let nama = "Budi";

Aktivitas 1 · Mengamati

Aktivitas 1 – Mengamati

Perhatikan kode berikut:

let nama = "Budi";
let umur = 16;
let nilai = 85;

console.log(nama);
console.log(umur);
console.log(nilai);

Jalankan kode tersebut menggunakan browser.

Pertanyaan

1. Apa yang ditampilkan pada Console?

Console menampilkan tiga baris: Budi, 16, dan 85.

2. Menurutmu, apa fungsi nama, umur, dan nilai?

Ketiganya adalah nama variable, yaitu tempat menyimpan data ("Budi", 16, dan 85) sehingga datanya bisa dipanggil lagi dengan menyebut namanya.

3. Apa yang terjadi jika kode berikut dijalankan?

console.log(nama);
Jika variable nama sudah dibuat sebelumnya (seperti pada kode di atas), Console menampilkan Budi. Jika belum pernah dibuat, akan muncul error ReferenceError: nama is not defined karena JavaScript tidak mengenal nama tersebut.

4. Menurut dugaanmu, apa yang dimaksud dengan variable?

Variable adalah tempat untuk menyimpan data yang diberi nama, agar data tersebut dapat digunakan kembali oleh program.

Aktivitas 6 · let & const

Aktivitas 6 – Mengenal let dan const

Penggunaan let

Perhatikan kode berikut:

let umur = 16;
umur = 17;
console.log(umur);

Hasilnya

Nilai didalam variabel bernama "usia" dideklarasikan 2 kali, pertama berisi 26, kedua berisi 27. Lalu ketika dijalankan tidak terjadi eror, isi dari variabelnya menjadi data yang dideklarasikan paling terbaru (terakhir)

Penggunaan const

Sekarang coba:

const nama = "Budi";
nama = "Andi";
console.log(nama);

Apa yang terjadi?

Muncul error TypeError: Assign ment to constant variable. Nilai variable yang dibuat dengan const tidak bisa dideklarasikan 2 kali atau lebih dengan isi data yang berbeda, sehingga console.log(nama) tidak dijalankan.

Kesimpulan Sementara

Lengkapi tabel berikut.

KeywordNilai dapat diubah?Kegunaan sederhana
letYa, dapat diubahMenyimpan data yang masih mungkin berubah
constTidak, tidak dapat diubahMenyimpan data yang tetap / tidak perlu diubah
INGAT!

Gunakan let untuk data yang masih mungkin berubah. Contoh:

let nilai = 80;
nilai = 90;

Gunakan const untuk data yang tidak perlu diubah. Contoh:

const namaSekolah = "SMKN 1 Garut";

Aktivitas 7 · Penamaan

Aktivitas 7 – Aturan Penamaan Variable

Perhatikan nama variable berikut:

let nama;
let namaSiswa;
let nama_siswa;
let umur2;

Beberapa aturan dasar:

✓ Diperbolehkan

let nama;
let namaSiswa;
let nama_siswa;
let nilai1;

✗ Tidak diperbolehkan

let 1nama;
let nama siswa;
let nama-siswa;

Perhatikan juga

JavaScript membedakan huruf besar dan kecil.

let nama = "Andi";
console.log(nama);

berbeda dengan:

console.log(Nama);

Aktivitas 11 – Debugging

Program berikut memiliki beberapa kesalahan.

Tugas: Temukan kesalahan tersebut dan perbaiki programnya.

Kode yang error

let nama siswa = "Budi";

let 2kelas = "XI RPL";

console.log(umur);
console.log(2kelas);

Program yang sudah diperbaiki

Apa saja kesalahan yang kamu temukan?

1. nama siswa memakai spasi, seharusnya digabung menjadi namaSiswa (di let dan di console.log).
2. 2kelas diawali angka, seharusnya diubah menjadi kelas2 (di let dan di console.log).
3. Nama variable pada console.log harus sama persis dengan nama saat variable dibuat (huruf besar-kecil juga berpengaruh).

Tugas Individu

Tugas Individu

Buat sebuah program JavaScript dengan tema: "Data Produk Sederhana"

Program harus memiliki minimal 6 variable:

  1. Nama produk
  2. Kategori
  3. Harga
  4. Stok
  5. Merek
  6. Status produk

Ketentuan

  • Minimal 6 variable.
  • Gunakan let dan const.
  • Gunakan nama variable yang benar.
  • Minimal terdapat data teks dan angka.
  • Program harus dapat dijalankan tanpa error.
  • Siswa harus mampu menjelaskan fungsi setiap variable.

Contoh:

const namaProduk = "Keyboard";
const kategori = "Perangkat Komputer";
const harga = 150000;
let stok = 10;
const merek = "ABC";
const tersedia = true;

console.log(namaProduk);
console.log(kategori);
console.log(harga);
console.log(stok);
console.log(merek);
console.log(tersedia);
